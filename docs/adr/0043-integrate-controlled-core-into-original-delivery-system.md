# ADR 0043: 将受控核心整合进原投递系统

## Status

Accepted

## Context

把受控核心作为独立产品入口会丢失原系统已经存在的 Agent API 配置、搜索、推荐、润色、会话续接和投递监控能力，也让用户面对两套割裂流程。

## Decision

原投递 WebUI 与 REST/WebSocket 会话继续作为正式产品入口。版本化候选人档案、加密 PDF 文件资源和受管浏览器作为其可靠内核：

- 投递会话必须绑定一个已确认的档案版本，不再读取“最新上传文件”或简历 JSON 缓存；
- 新 PDF 只生成可审核的变更，确认后建立独立版本；
- 原 Agent API、搜索、推荐、润色、消息续接和监控继续保留；
- 登录、人工接管、填表检查均在持久受管浏览器中完成，最终提交只由用户执行；
- React 任务前端保留为辅助诊断面，不再替代正式入口。

## Consequences

旧 Agent 编排与新核心通过明确适配边界协作。会话所需的明文 PDF 只在运行期临时物化，权威数据仍是加密文件资源和不可变档案版本。
