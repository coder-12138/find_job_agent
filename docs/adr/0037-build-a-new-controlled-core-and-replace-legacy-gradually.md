# 新建受控核心并渐进替换旧版 Agent 链路

冻结 `company_agent`、`orchestrator`、`session_manager` 和旧版 `memory` 所构成的 Agent 主链路，不再将其作为新架构的扩展基础。领域模型、SQLite 持久化、申请状态机、文件资源库和飞书招聘适配器在隔离模块中建立受控核心路径；只复用已验证的纯函数、选择器和页面识别逻辑。

首个垂直切片只覆盖单职位、单受管浏览器和原始简历基础申请路径。新旧路径不得同时修改同一职位申请，也不向求职者长期暴露两套产品入口。新路径稳定且迁移经过验证前，不删除旧数据；验证完成后再移除旧版 Agent 链路、腾讯文档能力和明文 JSON 业务存储。
